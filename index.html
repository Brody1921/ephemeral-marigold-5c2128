About this app

This is a local script editor and organizer. It saves your work in this browser on this device. It does not inject code into Roblox or execute scripts inside the Roblox app.

Script editor

Edit Lua text and save it on your phone.

For safety and compatibility, the Execute button in this editor checks your draft and shows a local preview only. It cannot run code inside Roblox on iOS.
