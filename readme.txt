DeltaX Studio — iPhone web app package

CONTENTS
- index.html: the mobile script editor and organizer
- manifest.webmanifest: installable web-app metadata

HOW TO USE ON IPHONE
1. This package needs to be hosted on an HTTPS website to be added to the iPhone Home Screen as an app.
2. Upload index.html and manifest.webmanifest to a static website host.
3. Open the HTTPS website in Safari.
4. Tap Share, then Add to Home Screen.

FEATURES
- Edit, save, import, and export Lua text
- Local script list and recent scripts
- Console-style draft checks
- Dark/light theme and autosave options

LIMITATION
This is a script editor, not a Roblox executor. iOS web apps cannot inject code into the Roblox app.
Scripts are saved in the browser's local storage, so export backups of important work.
